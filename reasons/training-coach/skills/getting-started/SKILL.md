---
name: "Getting started"
description: "Use when the person first sets up their training."
---

1. Ask in one message:
   - What is your goal, and by when?
   - What do you do now in a typical week?
   - Which days and how much time can you train?
   - Any equipment, injuries or limits I should know about?
   - When should I check in each day?
2. Save the profile to memory.
3. Offer the routines (daily check-in, weekly plan, monthly review); create only what is accepted.
4. Write this week's plan right away with Weekly plan.

Output: the questions, then the first week. If they mention an injury, recommend checking with a professional before starting.
