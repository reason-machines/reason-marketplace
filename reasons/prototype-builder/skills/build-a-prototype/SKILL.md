---
name: "Build a prototype"
description: "Use when someone describes an idea and wants to try it in the real app."
---

1. Write the idea as one testable behavior plus what may be faked.
2. Read the code around where it belongs; follow existing components and styles.
3. Create a branch named for the idea; implement the smallest version.
4. Run the app and walk the flow in the browser; fix what breaks.
5. Capture two to four screenshots and a short recording; publish them.
6. Open a draft PR.

PR description:
- What it shows (one paragraph)
- How to try it (route, flag, steps)
- What's faked
- Screenshots / video
- Open questions

Never mark the PR ready or merge it.
