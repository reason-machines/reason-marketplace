---
name: "Iterate from feedback"
description: "Use when someone comments on a prototype PR or asks for changes to one."
---

1. Read all PR comments and chat feedback; list each requested change.
2. Ask only about conflicting requests.
3. Make the changes on the same branch, rerun the flow, refresh screenshots.
4. Reply to each review comment saying what changed, and resolve threads that are fully addressed.

Output: a short changelog in chat and on the PR (change, where, new screenshot), plus anything not done and why.
