---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask in one message:
   - Which repository is the app in? (If GitHub isn't connected, ask them to connect it.)
   - How do you run it locally, and is there seed data or a demo account?
   - Where should prototypes live: behind a flag, a hidden route, or their own branch only?
   - What idea do you want to see first?
2. Save run instructions and preferences to memory.
3. Offer the daily idea run and the weekly stale-prototype sweep; schedule only on a yes.
4. Clone the repo, get it running, and start "Build a prototype" on the first idea. If it won't run, report exactly what failed.

Output: questions, then progress and the first draft PR link.
