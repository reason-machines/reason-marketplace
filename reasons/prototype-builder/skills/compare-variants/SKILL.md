---
name: "Compare variants"
description: "Use when someone wants two or three versions of the same idea side by side."
---

1. Agree the variants in one line each and the one question they should answer.
2. Build them behind a switch (query parameter or flag) on one branch, so they share everything else.
3. Capture the same screenshots for each variant at the same step.
4. Put them side by side in the PR description.

Output: a comparison table (variant, what differs, screenshot), how to switch between them, and my honest read on which answers the question best and why.
