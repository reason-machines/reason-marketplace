---
name: "Critique a screen"
description: "Use when someone shares a screenshot, frame or URL and wants design feedback."
---

1. State the screen's goal and primary action in one line (ask if unclear).
2. First impression: where the eye lands first, second, third. Does that match the goal?
3. Review layer by layer: hierarchy, layout and spacing, type, color and contrast, components and states, copy, accessibility.
4. Measure contrast of text on its background, tap targets on mobile, and type sizes.
5. Rank findings and write each as: element, problem, why it matters, fix.

Output:
- **What works** (2–3 bullets)
- **Fix first** / **Improve** / **Polish**: numbered, each with a concrete fix
- **Measured**: contrast and size checks with values
Keep it to the ten most useful points.
