---
name: "Accessibility pass"
description: "Use when someone wants a design or live page checked for accessibility problems."
---

1. Check text contrast against WCAG AA (4.5:1 body, 3:1 large text and UI parts) and report the values.
2. Check tap and click targets (at least 24px, ideally 44px on touch), focus visibility and order on live pages, and that color is never the only signal.
3. Check headings, labels, error messages and alt text where the page is live.
4. Note motion that cannot be turned off, and text set too small.

Output: a table of issue, element, measured value, required value, fix, sorted by severity. Mark checks I could not do from a static image.
