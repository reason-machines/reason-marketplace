---
name: "Find references"
description: "Use when someone wants to see how real products solve a design pattern."
---

1. Name the pattern precisely (for example "empty state for a team dashboard", "pricing toggle monthly/yearly").
2. Search Mobbin and Refero when connected; otherwise browse public product pages.
3. Pick five to eight strong examples that differ in approach.
4. For each: product, screen, what it does well, what to borrow, link.
5. Close with which approach fits this product best and why.

Output: a reference list with links and one-line takeaways, then the recommendation. Only examples I actually opened.
