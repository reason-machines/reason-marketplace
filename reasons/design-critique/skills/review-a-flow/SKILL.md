---
name: "Review a flow"
description: "Use when someone wants feedback on a multi-step flow like signup, onboarding or checkout."
---

1. Walk the flow in my browser (or read the frames in order). Count steps, fields and decisions.
2. For each step note: what the user must understand, what they must do, what could make them stop.
3. Find drop-off risks: unclear next step, surprise requirements, errors that blame the user, dead ends, missing back paths.
4. Suggest a shorter or clearer version of the flow.

Output: a step table (step, user's job, friction, fix), then a proposed flow outline with the steps removed or merged, then the top three changes to make first.
