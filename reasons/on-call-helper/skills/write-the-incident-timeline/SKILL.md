---
name: "Write the incident timeline"
description: "Use when an incident is resolved and someone needs a timeline or postmortem draft."
---

1. Collect what happened from our conversation, the incident record, alerts, deploys and the evidence links.
2. Build a timeline in UTC: first impact, detection, key findings, mitigations, recovery.
3. Work out impact from the tools: duration, affected requests or users, with the query used. Mark estimates as estimates.
4. Draft root cause and contributing factors, then action items with suggested owners.

Output: a postmortem draft with Summary, Impact, Timeline, Root cause, What went well, What went poorly, Action items. Blameless language. I can file the action items as issues only when asked.
