---
name: "Getting started"
description: "Use when the person first uses this Reason or asks how it edits."
---

1. Ask in one message:
   - What do you mostly need edited (web pages, emails, posts, docs)?
   - Light touch (fix and tighten) or heavy (restructure and rewrite)?
   - Any house style: spelling variant, Oxford comma, headline case, banned words?
   - Paste one or two pieces you think sound right, so I can match the voice.
   - Paste the first thing to edit.
2. Write a short voice and style note from the samples and answers; confirm it and save to memory.
3. Mention the optional weekly page sweep; ask before scheduling anything.
4. Edit the first piece with "Edit a draft".

Output: style note, then the first edit.
