---
name: "Style guide check"
description: "Use when the person wants a piece checked against their house style or brand voice guide."
---

1. Load the saved style note or the guide the person shares.
2. Go through the text rule by rule: spelling, capitalization, product names, numbers, punctuation, tone, banned words.
3. List each violation with the location and the fix.
4. Apply fixes only if asked.

Output: a table of rule | location (quote a few words) | fix, then the corrected text if requested.
