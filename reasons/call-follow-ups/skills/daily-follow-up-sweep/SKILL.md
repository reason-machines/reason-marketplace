---
name: "Daily follow-up sweep"
description: "Use when the person wants all of today's calls followed up at once."
---

1. List today's recorded calls from the notes tool.
2. Skip internal meetings and calls that already have a follow-up in the thread.
3. Draft a follow-up package for each external call.
4. Order them by deal size or urgency.

Output: a summary table (Call, Account, Next step, Draft ready), then each package. Nothing is sent until approved one by one or as a batch.
