---
name: "Scan accounts"
description: "Use when the person wants the tracked accounts checked for new or changed job posts."
---

1. For each tracked account, read its careers page and search job boards for current posts.
2. Compare with the saved snapshot: new, closed, changed.
3. Read each new post fully and match it against the signal list.
4. Rate matches Strong, Moderate or Weak, with the quoted line that triggered it.
5. Save the new snapshot.

Output: "Strong matches" table (Account, Role, Quote from post, Link, Date seen, Suggested contact, Angle), then "Other changes" as one line per account, then "Could not read" if any.
