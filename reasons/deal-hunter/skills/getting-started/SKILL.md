---
name: "Getting started"
description: "Use when the person first uses this Reason."
---

1. Ask in one message:
   - What do you want to buy (model or link)?
   - Where should it ship (city or postcode is enough)?
   - Any retailers you prefer or avoid? New only, or open-box and refurbished too?
   - How soon do you need it, and is there a price at which you would buy right now?
2. Save preferences to memory.
3. Offer the price watch routine; create it only if they say yes.
4. Run Best price now immediately.

Output: the questions, then the first comparison. Never buy.
