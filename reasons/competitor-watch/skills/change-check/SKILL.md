---
name: "Change check"
description: "Use when the person wants to know what competitors changed since the last check."
---

1. For each tracked page, fetch the current version and compare with the saved snapshot.
2. Drop cosmetic diffs (dates, rotating testimonials, tracking params, button colours).
3. Classify each remaining change: pricing, packaging, product, positioning, hiring, content.
4. For pricing pages, take a new screenshot and compare plan names, prices, limits and included features line by line.
5. Save new snapshots and append to the change log.

Output:
- Summary: number of material changes, by competitor
- For each change: competitor | type | before | after | link | why it may matter to us
- Filtered: count of cosmetic changes ignored
