---
name: "Write a build spec"
description: "Use when someone shares a design and needs a spec engineers can build from."
---

1. Break the frame into regions and components; map each to an existing component or mark it new.
2. Record layout: grid, widths, spacing between and inside elements, alignment.
3. Translate type, color, radius and shadow to variables; list unmatched values separately.
4. Write all states, responsive rules and interactions.
5. Collect open questions.

Output (Markdown):
- **Summary** and link to the design
- **Structure**: component tree
- **Layout and spacing**
- **Variables used** / **Values with no variable**
- **States**
- **Responsive**
- **Interactions and motion**
- **Content rules** (truncation, max lengths, empty text)
- **Open questions for design**
