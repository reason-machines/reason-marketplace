---
name: "Create build tickets"
description: "Use when a spec is approved and the person wants it split into tickets."
---

1. Split the spec into tickets an engineer can finish in a day or two: new components first, then the screen, then states and edge cases.
2. Each ticket has: title, the spec section it covers, acceptance criteria, design link, open questions that block it.
3. Show the list for approval.
4. Create the issues in Linear only after the person says yes, and link them back here.

Output: the ticket list, then the created issue links.
