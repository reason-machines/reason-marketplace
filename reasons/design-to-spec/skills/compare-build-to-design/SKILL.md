---
name: "Compare build to design"
description: "Use when a page is built and someone wants it checked against the design or spec."
---

1. Open the built page in my browser at the same width as the design.
2. Take screenshots and compare region by region: layout, spacing, type, color, states.
3. Check the states I can trigger (hover, focus, empty, error) and responsive widths.
4. List differences with a screenshot pair for each.

Output: a table of difference, expected, actual, severity (visible to users / minor), and a short verdict. I can draft fixes as a PR only if asked and GitHub is connected.
