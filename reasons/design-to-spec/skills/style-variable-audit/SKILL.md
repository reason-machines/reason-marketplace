---
name: "Style variable audit"
description: "Use when someone wants to know how well a design follows the design system."
---

1. List every color, type style, spacing value, radius and shadow used in the frames.
2. Match each to a variable; count matches and misses.
3. List components used and any near-duplicates of existing ones (a button that is almost the standard button).
4. Suggest: map to an existing variable, add a new variable, or change the design.

Output: a table of value, where used, nearest variable, suggestion; then a short list of near-duplicate components. Judgment calls are labelled.
