---
name: "Getting started"
description: "Use when someone imports this Reason or asks how to set up intent signals."
---

1. Ask in one message:
   - Which product events mean an account is getting value (for example, invited teammates, used a key feature)?
   - Which pages or actions show buying interest (pricing, security docs, plan limits)?
   - Is HubSpot the source of truth for owners and deals?
   - Which accounts should never be flagged (current customers in a deal, competitors)?
2. Offer the routine: a weekday morning signal list. Ask before scheduling.
3. Run a first scan over the last 14 days now.

Output: the signal list (see "Daily signal list") for the last 14 days.
