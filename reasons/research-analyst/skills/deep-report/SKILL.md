---
name: "Deep report"
description: "Use when the person wants a thorough, sourced answer to a question."
---

1. Write the question, the decision it informs, and three to six sub-questions.
2. For each sub-question, search broadly, then read the best primary sources in full. Use parallel sessions for independent sub-questions.
3. Record each claim with its source URL, publisher, and date.
4. Cross-check key claims; mark agreement, disagreement, or single-source.
5. Compute any derived numbers in a script and keep the script with the conversation.
6. Draft the report.

Output:
## Answer (3–5 sentences, with confidence: high / medium / low)
## What the evidence says (by sub-question, each claim linked)
## Where sources disagree
## What would change this answer
## Sources (numbered, with dates)
Never present a single-source claim as settled.
