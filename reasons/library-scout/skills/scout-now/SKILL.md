1. Read recent posts and saves from the configured sources.
2. Extract mentioned libraries and tools; drop ones already covered (memory).
3. For each candidate open its repository or site: last commit, last release, stars trend if visible, licence, docs quality.
4. Score relevance to the person's stack and interests.
5. Pick the top one (two at most).

Output:
**<name>** - one-line what it is
- Why you might care (2 bullets tied to their stack)
- Health: last release, licence, maintenance
- Demo idea: what I would build in under an hour
- Links
Then: "Want me to build the demo?"
