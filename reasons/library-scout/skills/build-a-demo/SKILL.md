---
name: "Build a demo"
description: "Use when the person approves a pick and wants to see it working."
---

1. Write a short plan: goal, the smallest example that shows the main feature, success check.
2. Create a fresh project in the sandbox and install the library from its official registry.
3. Follow the official quickstart first, then extend to the demo idea.
4. Run it; capture output, a screenshot, or a short browser recording if it has a UI.
5. If the person chose GitHub, push to a new branch and open a pull request only after they confirm.
6. Keep the source files attached to the conversation.

Output: what was built, how to run it, the result (output or media), what was rough, and a verdict: adopt, watch, or skip.
