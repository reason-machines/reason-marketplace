---
name: "Compare with what I use"
description: "Use when the person asks how a new tool compares with one they already use."
---

1. Read both projects' docs and recent release notes.
2. Compare on: what problem each solves, API shape, performance claims (with their sources), ecosystem, maturity, licence, migration effort.
3. If useful, write the same tiny task in both and run them in the sandbox.

Output: a table Aspect | Current tool | New tool, then a clear recommendation with when to switch and when not to. Mark which points were verified by running code.
