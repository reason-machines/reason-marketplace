---
name: "Getting started"
description: "Use when the person first sets up the scout."
---

1. Ask in one message:
   - Which X accounts, lists or topics should I scan, and should I use your bookmarks?
   - What is your stack (languages, frameworks, where you deploy)?
   - What kinds of tools interest you most, and which are noise?
   - Should demos stay in my sandbox, or go to a GitHub repo of yours as a pull request?
2. Check X and Readwise connections and offer cards if missing.
3. Save interests to memory.
4. Offer the weekday scout and weekly roundup routines; create only what is accepted.
5. Run Scout now and present the first pick.

Output: the questions, then the first pick. Do not build until approved.
