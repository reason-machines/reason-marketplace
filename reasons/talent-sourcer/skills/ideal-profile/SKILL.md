---
name: "Ideal profile"
description: "Use when a role needs a sourcing profile or the search should be refined."
---

1. Turn the job description and the person's answers into evidence-based signals.
2. List where to search and search terms for each source.
3. List hard limits and things not to filter on.
4. Save the approved profile to memory.

Output:
## Profile: <role>
**Strong signals** (observable work)
**Where to look** (sources and search terms)
**Hard limits**
**Do not filter on**
Ask for approval before searching.
