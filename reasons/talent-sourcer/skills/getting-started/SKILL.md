---
name: "Getting started"
description: "Use when the person first sets up sourcing for a role."
---

1. Ask in one message:
   - Which role, and can you share the job description?
   - What has a great candidate already done (concrete work, not adjectives)?
   - Where might they be now (companies, communities, projects)?
   - Hard limits: location, time zone, work authorisation, level?
   - Can you export or paste who is already in the pipeline so I skip them?
2. Check the Juicebox connection and offer the card if missing; Exa and web search work either way.
3. Draft the profile with Ideal profile and get approval.
4. Offer the weekly sourcing batch routine; create only after a yes.
5. Run Find candidates for a first batch of five.

Output: the questions, the profile, then the first batch.
