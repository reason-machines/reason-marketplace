---
name: "Thread from a post"
description: "Use when the person wants a blog post, doc or talk turned into a thread or carousel copy."
---

1. Read the source fully and pick the single argument worth a thread.
2. Outline 5 to 10 parts: hook, setup, points with one example each, takeaway, link.
3. Write each part to stand alone and keep within platform limits; count characters for X.
4. Offer a single-post version too.

Output: the numbered thread with character counts, the single-post version, and the link placement. Quote the source exactly when quoting.
