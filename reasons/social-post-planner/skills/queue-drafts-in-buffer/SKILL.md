---
name: "Queue drafts in Buffer"
description: "Use when the person approves drafts and wants them placed in Buffer."
---

1. Confirm which drafts are approved and for which channels and dates.
2. If Buffer is not connected, show the connection card and offer a copy-ready list instead.
3. Create each as a draft (not scheduled to publish) in the right channel, with the proposed date in a note if drafts cannot carry one.
4. Read back what Buffer saved.

Output: list of drafts created with links, and anything that failed with the error. Never set a post to publish.
