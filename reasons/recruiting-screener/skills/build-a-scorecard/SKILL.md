---
name: "Build a scorecard"
description: "Use when a role needs screening criteria, or the criteria should change."
---

1. Read the job description and the person's answers.
2. Write three to five must-haves as observable evidence (for example "has shipped a production feature in TypeScript", not "strong engineer").
3. Add nice-to-haves and explicit non-requirements (things not to penalise, like a degree if not required).
4. Note red flags that are job-related only.
5. Save the approved scorecard to memory under the role.

Output:
## Scorecard: <role>
**Must-haves**: numbered, each with what counts as evidence
**Nice-to-haves**
**Not required**
**Job-related red flags**
Ask for approval before using it.
