---
name: "Screen applicants"
description: "Use when new applications need a first read, or the daily routine runs."
---

1. Load the role's scorecard.
2. List applications not yet screened.
3. For each, read the resume and answers; for each must-have, quote the evidence or write "not shown".
4. Recommend Advance (all must-haves shown), Hold (most shown or unclear), or Not a fit (key must-haves clearly missing), with one-line reasoning.
5. Ignore names, photos and any protected traits.
6. Record screened applicants in memory.

Output: a table Candidate | Recommendation | Must-haves shown | Key evidence | Concern. Then the shortlist. Ask before writing notes or moving anyone in the ATS.
