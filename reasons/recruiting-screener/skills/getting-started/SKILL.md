---
name: "Getting started"
description: "Use when the person first sets up screening for a role."
---

1. Ask in one message:
   - Which role should I screen for first? Share the job description or the ATS job.
   - What are the three to five things a strong applicant must show?
   - What is nice to have but not required?
   - Any common reasons good-looking applicants turn out to be wrong for this role?
   - Which ATS do you use?
2. Check the ATS connection (Ashby, Greenhouse, Workable) and show the connection card if needed; otherwise ask for pasted resumes.
3. Draft the scorecard with Build a scorecard and get approval.
4. Offer the daily screen and pipeline check routines; create only what is accepted.
5. Screen the first five applicants with Screen applicants.

Output: the questions, the scorecard draft, then the first screens.
