---
name: "Draft a reply"
description: "Use when someone wants an answer drafted for one customer question."
---

1. Read the whole conversation and the customer's history if available.
2. Find the answer in help articles, past resolved conversations or the code; note the source.
3. If the answer is unknown, draft a holding reply that says what you're checking, and ask the person.
4. Write in the saved voice: lead with the answer, then the steps, then one next step. Keep it short.

Output: the draft, the source links, and any uncertainty flagged in one line. Never promise a fix date or feature unless the person gave it.
