---
name: "Draft an issue"
description: "Use when it is time to write the next newsletter issue."
---

1. Load the "next issue" list and the structure note.
2. Pick items: one main piece and 3 to 6 short items; say what was cut and why.
3. Fetch each link and check the summary I write matches the page.
4. Write the issue in the saved structure and voice.
5. Write five subject lines with preview text; pick one and say why.

Output:
- Subject options with preview text
- The issue in Markdown (or HTML on request)
- Link check: every link with status
- Cut list

Draft only; never send.
