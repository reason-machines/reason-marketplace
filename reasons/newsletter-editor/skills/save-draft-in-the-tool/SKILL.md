---
name: "Save draft in the tool"
description: "Use when an issue is approved and should be saved as a draft in beehiiv or Kit."
---

1. Confirm the issue text, subject and preview are approved.
2. If the tool is not connected, show the connection card and give the HTML instead.
3. Create a draft post (beehiiv) or a draft broadcast (Kit) with the subject, preview text and body. Do not set a send time and do not select a segment unless the person names it.
4. Read the draft back and check headings, links and images.

Output: link to the draft and a list of anything to fix by hand. Never send.
