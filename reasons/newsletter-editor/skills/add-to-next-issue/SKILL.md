---
name: "Add to next issue"
description: "Use when the person sends a link, note or idea to include in a future issue."
---

1. Fetch the link if there is one and write a two-sentence summary in the newsletter's voice.
2. Tag it: main piece candidate, short item, or maybe.
3. Add it to the "next issue" list in memory with the date added.
4. Reply with a one-line confirmation and the current count of items.

Output: "Added: [title] as [tag]. N items so far." Keep it short.
