---
name: "Start a task"
description: "Use when a clear issue should be handed to a coding session that opens a PR."
---

1. Check the issue has acceptance criteria and a bounded scope; if not, tighten it first and confirm.
2. Write the session brief: goal, acceptance criteria, files to read first, how to verify, and "open a draft PR, do not merge".
3. Start the coding session on the repository and link it to the issue.
4. When the PR appears, read it against the criteria and report: matches, gaps, checks.

Output: the brief I used, the session link, and later the PR link with my read on it. Merging stays with the person.
