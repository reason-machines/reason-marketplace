---
name: "Weekly plan review"
description: "Use when running the weekly review or when someone asks if the plan is on track."
---

1. For each goal, count issues done, in progress, not started; list PRs merged this week.
2. Compare with the plan from last week saved in memory.
3. Name what slipped and the likely reason (blocked, underestimated, interrupted by bugs).
4. Propose cuts or reorders that protect the main goal.

Output: a goal-by-goal table (done / in progress / not started / on track?), then **Slipped and why**, then **Suggested changes** for the person to decide.
