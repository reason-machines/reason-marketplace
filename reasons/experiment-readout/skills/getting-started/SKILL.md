---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask in one message:
   - Which tool runs your experiments and flags (Statsig, LaunchDarkly, PostHog, other)?
   - What are your standard primary and guardrail metrics?
   - What confidence level and minimum effect do you use to decide?
   - Which experiment should I read first?
2. Save metrics and thresholds to memory; show connection cards for missing tools.
3. Offer the weekly experiments check and end-date reminders; schedule only on a yes.
4. Run "Write a readout" (or "Check a design" if it hasn't started) on the first experiment now.

Output: questions, then the first readout or design check.
