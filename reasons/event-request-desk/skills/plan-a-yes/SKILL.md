---
name: "Plan a yes"
description: "Use when a request was accepted and the work to deliver it needs organizing."
---

1. List what's needed: contract, payment, speaker, talk title and abstract, booth or assets, travel, promotion.
2. Assign an owner and due date to each, counting back from the event.
3. Draft the speaker abstract or sponsor copy if asked.
4. Save the plan and offer a one-off follow-up before each deadline.

Output: a checklist table (task, owner, due, status) and any drafts.
