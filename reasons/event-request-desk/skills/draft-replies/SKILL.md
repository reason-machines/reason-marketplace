---
name: "Draft replies"
description: "Use when decisions are made and replies need writing."
---

1. For each decided request, write the reply in the saved tone.
2. Yes: confirm the specifics and ask for the contract or next step.
3. Maybe: ask the one or two questions that would decide it.
4. No: thank them, decline briefly, and leave the door open only if true.

Output: drafts grouped by decision, each with the recipient and subject. Send nothing until approved.
