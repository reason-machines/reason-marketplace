---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask these in one message:
   - What are you building, and who is it for (one line)?
   - Where do specs live today (Linear, Notion, a doc, nowhere)? Do you have a template I should follow?
   - Which repository holds the product, if GitHub is connected?
   - What is one idea or ask you want specced first? Paste anything you have.
   - Any rules your team follows (no new settings, mobile first, ship behind a flag)?
2. Save the answers to memory.
3. Offer the two routines (weekly spec hygiene, Friday request sweep) and ask whether to schedule either. Do not schedule without a yes.
4. Write a first spec right away from what they gave, using the "Write a spec" playbook. If they gave nothing, write a short sample spec for a plausible feature of their product and label it a sample.

Output: the questions, then (after answers) the first spec and a one-line offer of the routines.
