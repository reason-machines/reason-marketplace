---
name: "Draft a change"
description: "Use when the person agrees a fix and wants the exact campaign change written up or applied."
---

1. Write the change precisely: platform, account, campaign, field, current value, new value, and why.
2. Show the expected effect and how we will know in three to seven days.
3. Ask for an explicit yes for this exact change.
4. Only after the yes, and only if the connected plugin supports it, apply it; then read it back to confirm. Otherwise give step-by-step instructions to do it in the platform.
5. Save the change and date to memory so later checks account for it.

Output: the change card (before → after), confirmation status, and the check-back date. Offer a one-off follow-up to review the result.
