---
name: "Getting started"
description: "Use when someone first sets up this Reason for their team."
---

1. Ask in one message:
   - Who is on the team, and what are their GitHub and Linear or Jira handles?
   - Which repositories and projects count as this team's work?
   - What time and time zone should the standup be ready, and where should it go (here or a Slack channel)?
   - Any format you like: per person, per project, or blockers first?
2. Show connection cards for Linear or Jira if they use one and it is not connected.
3. Offer the routines (daily standup, weekly recap, blocker alert). Schedule only on a yes.
4. Write today's standup now from the last working day so they can judge it.
5. Save the roster, scope and format to memory.
