---
name: "Find savings"
description: "Use when someone wants to cut software spend with evidence."
---

1. For each tool, compare seats paid vs active (from exports or admin data given).
2. Find overlaps: two tools for the same job.
3. Check the vendor's pricing page for a plan that fits real usage; note the link.
4. Note annual vs monthly options and discounts for prepaying.
5. Rank by annual saving and effort.

Output: table (tool, action, annual saving, evidence, effort, owner to ask), and the total. Then a draft message per owner asking to confirm. Never act on a saving without approval.
