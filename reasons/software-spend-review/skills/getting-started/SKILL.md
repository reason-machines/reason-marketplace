---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask in one message:
   - Where does software spend show up (Ramp, Brex, another card, invoices, accounting export)?
   - Is cloud spend in scope, and is Vantage connected?
   - Who approves cancellations or downgrades, and above what amount?
   - Any tools that are untouchable?
2. Save rules to memory; show connection cards for missing tools or ask for a CSV.
3. Offer the monthly review, renewal radar and cloud cost check; schedule only on a yes.
4. Build the first inventory now with "Build the inventory".

Output: questions, then the inventory and the first savings list.
