---
name: "Resize for every channel"
description: "Use when an existing graphic needs versions for other sizes and platforms."
---

1. Take the source design and list the target sizes.
2. For each size, re-lay the content rather than squashing it: move text, re-crop images, keep margins safe.
3. Check each version at phone size for legibility.
4. Name files by channel and size.

Output: a list of versions with links, and any version where something had to be cut, with what was cut.
