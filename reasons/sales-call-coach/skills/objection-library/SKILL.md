---
name: "Objection library"
description: "Use when the person wants to see how objections are being handled across calls."
---

1. Scan the chosen calls for pushback: price, timing, competitor, security, need.
2. Group them by type and count how often each appears.
3. For each type, quote the best real response we gave and one that fell flat.
4. Suggest a stronger response grounded in what worked.

Output: a table (Objection, Count, Best response quote, Weak response quote, Suggested approach), with call links or timestamps.
