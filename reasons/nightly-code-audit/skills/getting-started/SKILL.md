---
name: "Getting started"
description: "Use when someone first sets up the nightly audit or asks how it works."
---

1. Ask in one message:
   - Which repository (GitHub must be connected), and which folders matter most or are off-limits?
   - What do you want fixed first: dead code, error handling, test gaps, outdated dependencies, or anything I find?
   - How big may a PR be, and who should review it?
   - What time should the audit run, and in which time zone?
2. Read the repo's README, contribution guide and test commands, and confirm I can build it.
3. Offer the routines (nightly audit, weekly digest). Schedule only on a yes.
4. Run a first audit now on one small area and open a draft PR, so they see the result.
5. Save the rotation, limits and preferences to memory.
