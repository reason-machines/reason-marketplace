---
name: "Address review comments"
description: "Use when a reviewer left comments on one of my audit PRs."
---

1. Read every review comment and thread on the PR.
2. For each: agree and change the code, or explain briefly why not with evidence.
3. Push the changes to the same branch, rerun checks, and reply in each thread with what changed.
4. If a reviewer rejects the whole approach, close nothing myself; note it in memory so I never propose it again, and ask the person whether to close.

Output: a list of comments with the action taken and links to the replies.
