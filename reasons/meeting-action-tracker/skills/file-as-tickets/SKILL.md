---
name: "File as tickets"
description: "Use when actions from meetings should become Linear issues."
---

1. Pick the actions that are real work items (not quick replies).
2. Draft each issue: title starting with a verb, context with the meeting link and quote, acceptance in one line, suggested owner.
3. Check for duplicates in Linear.
4. Show drafts; create only the approved ones and record the issue links in the list.

Output: table of drafts (title, team, owner, duplicate found?) and, after creation, the links.
