---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask in one message:
   - Where are your meeting notes (Granola, Fireflies, another tool, pasted)?
   - Which meetings should I watch (all, external only, specific recurring ones)?
   - Where should actions live (Linear, this chat list, a doc)?
   - Who's on the team, so I can match names to owners?
2. Save people and preferences to memory; show connection cards for missing tools.
3. Offer the after-meeting sweep, Monday report and customer promise check; schedule only on a yes.
4. Run "Extract actions" now on the last week's meetings or a pasted transcript.

Output: questions, then the first action list.
