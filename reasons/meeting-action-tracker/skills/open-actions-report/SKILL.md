---
name: "Open actions report"
description: "Use when the Monday report runs or someone asks what's still open."
---

1. Read the saved list; check Linear (if used) for status changes.
2. Scan recent meetings for items reported done.
3. Group: overdue, due this week, no date, no owner, done since last report.

Output: those five groups as short tables (item, owner, due, source meeting link). End with the three items most worth chasing and a draft nudge for each, sent only on approval.
