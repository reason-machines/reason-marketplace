---
name: "Event plan"
description: "Use when the person needs a timeline and task list for an event."
---

1. Work backwards from the date: venue, catering, AV, invites, registration, speakers, swag, travel, signage, staffing, follow-up.
2. Give each task an owner (ask if unknown), a due date and a dependency.
3. Highlight the critical path and the next three deadlines.
4. Save it to Notion or Airtable if connected, or as a file here.

Output: table of task | owner | due | depends on | status, sorted by due date, with the critical path marked.
