---
name: "Weekly metrics digest"
description: "Use when the weekly digest routine runs or someone asks for this week's numbers."
---

1. Read the key metrics and their definitions from memory.
2. Pull this week, last week, and the trailing 4-week average for each.
3. Flag movers beyond the normal range; for each, run a short version of "Explain a change".
4. Note any data quality problem found (missing days, tracking changes).

Output:
- Headline: the one thing worth knowing this week
- Table: metric, this week, last week, 4-week avg, change
- Movers explained (two lines each)
- Data notes

Keep it to one screen. Never fill in a missing metric with an estimate without labelling it.
