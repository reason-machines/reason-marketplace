---
name: "Getting started"
description: "Use when someone first imports this Reason or asks what it can do."
---

1. Ask in one message:
   - Where does your data live (PostHog, Hex, Amplitude, Mixpanel, spreadsheets, a database export)?
   - Which three to five metrics matter most, and how do you define each today?
   - Who should be excluded (staff, test accounts, a domain)?
   - What question do you want answered first?
2. Save definitions and exclusions to memory.
3. Show connection cards for any listed tool not yet connected; otherwise ask for an export.
4. Offer the weekly digest, daily anomaly check and monthly retention routines; schedule only on a yes.
5. Answer the first question now with the "Answer a data question" playbook. If no data is available yet, explain exactly which export to upload.

Output: the questions, then the first answer with chart and method.
