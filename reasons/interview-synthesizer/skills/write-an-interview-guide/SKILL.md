---
name: "Write an interview guide"
description: "Use when someone is about to run interviews and needs questions."
---

1. Restate the research question and the decision it feeds.
2. Write a warm-up, then questions about the last real time the participant did the task (past behavior beats hypotheticals).
3. Add probes for each core question (what happened next, why, what did you try).
4. Add a short task if there's a prototype or product to try, with what to observe.
5. Flag leading questions and rewrite them neutrally.

Output: a guide in sections (intro script, warm-up, core questions with probes, task, wrap-up), sized for the session length given.
