---
name: "Synthesize sessions"
description: "Use when there are transcripts or notes from several interviews to make sense of."
---

1. Read each session; note observations with participant id and timestamp.
2. Cluster observations into findings across participants.
3. For each finding: how many participants, which segments, strongest quotes, behavior vs stated.
4. List surprises and contradictions separately.
5. Write recommendations tied to findings, each with confidence (high/medium/low).

Output:
- Summary (five bullets max)
- Findings: title, participants (x of n), evidence quotes, implication
- Surprises
- Recommendations with confidence
- Open questions for next round

Never upgrade one person's comment into a pattern.
