---
name: "Draft buyer questions"
description: "Use when the person needs a question set to track and has none, or wants to expand it."
---

1. Read the person's homepage, pricing, product pages and docs, plus two competitors' homepages.
2. Write questions the way a buyer types them, across stages: problem ("how do I…"), category ("best … for …"), comparison ("X vs Y", "alternatives to X"), and evaluation ("is X good for …", "X pricing").
3. Remove duplicates and questions no buyer would ask.
4. Tag each with stage and topic.

Output: a table of 20 to 40 questions with stage and topic, and five marked as the core set to check every week.

Save the approved set to memory.
