---
name: "Audit a page"
description: "Use when someone wants the images on a web page checked for missing or weak alt text."
---

1. Open the page in my browser and list every image, including linked images and icons.
2. Read each image's current alt text and its surrounding content.
3. Grade each: missing, empty but should not be, empty and correct, weak (vague, file name, keyword stuffed), or good.
4. Draft better alt text where needed.

Output: summary counts by grade, then a table of image, current alt, grade, suggested alt. Point out the worst problems first (functional images with no alt).
