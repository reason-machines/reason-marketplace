---
name: "Describe a chart or diagram"
description: "Use when an image carries data or steps that need a full text alternative."
---

1. Identify the chart type and what it compares, its axes and units.
2. Read the values I can see; mark any I cannot read exactly as approximate.
3. Write a short alt (what it shows and the main takeaway) and a long description (the key values or steps in order).
4. For a diagram, describe the parts and how they connect, in reading order.

Output: short alt, long description, and an optional data table in Markdown. Never invent values that are not visible.
