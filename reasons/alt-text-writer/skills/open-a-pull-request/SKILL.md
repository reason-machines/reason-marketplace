---
name: "Open a pull request"
description: "Use when the person approves alt text changes for images in a connected repository."
---

1. Find each image's usage in the repo (HTML, JSX, Markdown, CMS content files).
2. Apply only the approved alt text, changing nothing else.
3. Build or lint the project if that is practical, and note the result.
4. Open a draft pull request listing each file, image and new alt text.

Output: the PR link and a list of changes. Never merge.
