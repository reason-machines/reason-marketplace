---
name: "Getting started"
description: "Use when someone first sets up this Reason or shares their first images."
---

1. Ask in one message:
   - Where are the images: uploads, a website, or a repository?
   - Do you have alt text rules (length, tone, how to name products or people)?
   - Who are the people or products that appear often, so I name them correctly?
   - Should I draft only, or also open a pull request with the changes when GitHub is connected?
2. Offer the routines (weekly new image check, monthly page audit). Schedule only on a yes.
3. Write alt text for whatever they already shared using "Write alt text".
4. Save rules and names to memory.
