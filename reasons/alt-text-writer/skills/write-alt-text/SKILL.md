---
name: "Write alt text"
description: "Use when someone shares one or more images and wants alt text."
---

1. For each image, find its context: the page, caption or the person's note. Ask if there is none and the purpose is unclear.
2. Decide its role: informative, functional or decorative.
3. Write the alt text: the key point first, under 125 characters when possible, no "image of".
4. For charts, diagrams or screenshots with dense text, also write a longer description.

Output: a table with image (file name or position), role, alt text, character count, and long description when needed. Decorative images get an empty alt with a note.
