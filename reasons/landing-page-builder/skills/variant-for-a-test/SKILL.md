---
name: "Variant for a test"
description: "Use when someone wants an alternative version of a page to compare against the current one."
---

1. Pick one variable to change (headline, offer framing, proof placement, call to action) so the result means something.
2. Write the hypothesis: what changes, why it should help, and the metric that decides.
3. Build the variant as a separate draft.
4. Note how to split traffic in their tool; I don't change live traffic myself.

Output: hypothesis, the variant's preview link, a side-by-side of what changed, and the metric to watch.
