---
name: "Reproduce a bug report"
description: "Use when someone reports a bug and wants it confirmed and described precisely."
---

1. Read the report (and its Jam recording, console and network data if it came from Jam).
2. Try to reproduce in my browser with the same steps, browser width and account type.
3. Narrow it: the smallest set of steps that triggers it, and what does not trigger it.
4. Record a short video of the reproduction.

Output: **Reproduced: yes / no / sometimes**, minimal steps, expected vs actual, evidence links, likely area of code if obvious. Draft a bug report; file it in Linear only when asked.
