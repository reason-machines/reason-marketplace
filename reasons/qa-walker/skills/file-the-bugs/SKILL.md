---
name: "File the bugs"
description: "Use when the person approves filing the failures from a QA run."
---

1. Take only the failures the person approved.
2. Check Linear for an existing issue on the same bug; if one exists, offer to add the new evidence as a comment instead.
3. Write each issue: title (what breaks, where), steps, expected, actual, environment and URL, evidence links, severity suggestion.
4. Create the issues and link them back in our conversation.

Output: list of created or updated issues with links.
