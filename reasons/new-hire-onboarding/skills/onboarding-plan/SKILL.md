---
name: "Onboarding plan"
description: "Use when a new hire has accepted and needs a plan."
---

1. Collect: name, role, team, manager, buddy, start date, location or remote.
2. Start from the saved template and adapt to the role and team.
3. Write the plan with owners and dates: Before day one, Day one, Week one, Weeks two to four, with one or two concrete first-month goals for the manager to confirm.
4. If Notion is connected and the person agrees, create the new hire's page from it.

Output:
## Onboarding: <name>, <role>, starts <date>
Sections as above, each a checklist: [ ] item - owner - due date.
Ask before creating any page.
