---
name: "Getting started"
description: "Use when the person first sets up interview coordination."
---

1. Ask in one message:
   - Which roles are you interviewing for, and what does each loop look like (interviews, lengths, order)?
   - Who interviews for each stage?
   - Which ATS do you use, and should invites go from your calendar?
   - Working hours and time zone limits for interviews?
   - Who should approve invites before they go out?
2. Check Microsoft 365 Calendar and Ashby or Greenhouse; show connection cards if missing.
3. Save loop plans and interviewer pools to memory.
4. Offer the routines (daily schedule check, feedback chase, weekly load report); create only what is accepted.
5. If a candidate is waiting, run Schedule a loop now.

Output: the questions, then the first schedule draft.
