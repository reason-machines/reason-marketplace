---
name: "Answer a reporting question"
description: "Use when the person asks an ad-hoc question about paid media performance."
---

1. Restate the question with the exact metric, period, channel and filter.
2. Pull only the data needed; if the definition is ambiguous (which conversion, which window), say which one I used.
3. Compute the answer and show the calculation.
4. Add one line of context: is that good versus target or history?

Output: the answer in one sentence, a small supporting table, and the source with date range. If the data is not available, say exactly what is missing and how to get it.
