---
name: "Inspect one deal"
description: "Use when the person names a deal and wants to know if it is really qualified."
---

1. Pull the deal, stage history, contacts, calls and notes.
2. For each criterion in the framework, search transcripts for the buyer's words that prove it.
3. Mark Proven, Partial or Missing. Partial means mentioned but not confirmed.
4. Write the questions that would close each gap.

Output:
- Deal, stage, amount, close date (one line)
- Scorecard table (Criterion, Status, Evidence quote, Source and timestamp)
- Verdict: supports the stage / does not yet, in one sentence
- Questions for the next call
