---
name: "Proof library report"
description: "Use when the person asks what proof exists and what is approved."
---

1. Read the proof library from memory.
2. Count by customer, type and status.
3. Flag drafts waiting on approval for more than two weeks.
4. Note themes with little proof (for example, no quotes about support or security yet).

Output: a summary table (Customer, Quotes, Approved, Waiting), a list of approvals to chase, and the themes that need more proof.
