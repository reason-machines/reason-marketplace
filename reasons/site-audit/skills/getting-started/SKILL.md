---
name: "Getting started"
description: "Use when the person first asks for a site audit or sets up regular audits."
---

1. Ask in one message:
   - Which domain, and which five pages matter most?
   - Is Ahrefs or Firecrawl connected?
   - Is the site's code in a GitHub repository I can open pull requests on? Which one?
   - What is the site's main goal: signups, demos, sales, reading?
   - Anything off limits (staging areas, gated pages)?
2. Save the domain, key pages and goal to memory.
3. Offer the monthly audit diff and weekly broken link check; ask before scheduling.
4. Run "Full audit" now, starting with the key pages.

Output: confirmed scope, routine offer, the audit.
