---
name: "Fix as pull request"
description: "Use when the person wants audit fixes applied in the site's repository."
---

1. Confirm the repository and which issues to fix.
2. Clone the repo, find where each issue lives (templates, components, content files), and make the smallest correct change: titles and meta tags, alt text, broken links, heading order, image sizes, schema.
3. Build or run the site locally and re-check the fixed pages.
4. Open one pull request per area with a clear description: issue, fix, before and after evidence.

Output: links to the pull requests with what each changes. Do not merge unless the person asks.
