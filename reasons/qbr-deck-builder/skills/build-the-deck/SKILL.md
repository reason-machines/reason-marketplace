---
name: "Build the deck"
description: "Use when the outline is agreed and the person wants the actual slides."
---

1. Use the uploaded template if there is one; otherwise a clean, plain layout.
2. Build each slide: title as a statement, one chart or three bullets at most.
3. Make charts from the real data with a script on my computer.
4. Write speaker notes with sources for every number.
5. Save as .pptx and attach it to the conversation.

Output: the attached deck, plus a list of numbers I could not verify and slides that need the person's input.
