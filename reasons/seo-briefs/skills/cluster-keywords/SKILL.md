---
name: "Cluster keywords"
description: "Use when the person has a keyword list or export and wants it organized into page-sized topics."
---

1. Load the list; normalize case, remove duplicates and obviously irrelevant terms (note what was removed).
2. Classify intent for each keyword: informational, commercial, transactional, navigational.
3. Group keywords that a single page could satisfy (same intent, same answer). Use the overlap of top-ranking URLs when the plugin provides it; otherwise judge by meaning and say so.
4. For each cluster pick a primary keyword (highest volume that matches the intent) and note total volume and median difficulty from the data.
5. Check whether the person already has a page for it.

Output: table with cluster | primary keyword | variants | intent | total volume | difficulty | existing page | recommendation (new page, update, skip).
