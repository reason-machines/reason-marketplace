---
name: "Optimize an existing page"
description: "Use when the person wants a specific live page improved for search and answer engines."
---

1. Fetch the page and record its title, meta description, headings, word count, internal links and last updated date.
2. Find the queries it targets (from the plugin, or ask).
3. Compare it with the top three results for its main query.
4. List concrete edits: a better title and meta description, missing sections, questions to answer directly, outdated facts, internal links to add, images needing alt text.

Output: an edit list ordered by impact, with the suggested text written out for titles, meta descriptions and new section openings. Never change the page myself.
