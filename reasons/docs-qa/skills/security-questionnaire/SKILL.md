---
name: "Security questionnaire"
description: "Use when the person uploads a security or vendor questionnaire to fill in."
---

1. Read the questionnaire and list every question.
2. Answer each from the security docs, trust page and knowledge base, with a citation.
3. Mark each answer Confident, Needs review or No source.
4. Never guess on security; unanswered items go to the person.

Output: a filled spreadsheet or document attached, plus a summary of items needing review.
