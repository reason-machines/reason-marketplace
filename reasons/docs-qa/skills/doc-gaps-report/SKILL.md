---
name: "Doc gaps report"
description: "Use when the docs owner wants to know what is missing or outdated."
---

1. Read the saved list of questions with no good source.
2. Group them by topic and count how often each came up.
3. Note pages that contradict each other or describe old behavior.
4. Suggest a title and outline for each missing page.

Output: a table (Topic, Times asked, Example question, Suggested page), and a list of contradictions with links.
