---
name: "Answer a question"
description: "Use when anyone asks a product, setup or policy question."
---

1. Search the public docs, then Guru and Notion, then the code if needed.
2. Read the most relevant pages fully, not just snippets.
3. Write the answer: one or two sentences first, then steps or details.
4. Add a citation after each claim.
5. Note anything uncertain or conflicting.

Output:
- Answer (short)
- Details or steps
- Sources (links, marked internal or public)
- "Not covered by docs" if part of the question had no source
