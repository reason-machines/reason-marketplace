---
name: "Getting started"
description: "Use when the person first sets up their plant log."
---

1. Ask in one message:
   - Which plants do you have? Send a photo of each if you can.
   - Which rooms and windows are they in, and which way do the windows face?
   - Does your home get dry or cold in winter? Any pets or small children?
   - How often are you away, and which day suits a weekly plant round?
2. Save home details to memory.
3. Offer the routines (weekly round, monthly journal, seasonal adjustment); create only what is accepted.
4. For each plant photo received, run Add a plant.

Output: the questions, then the first plants added to the log.
