---
name: "Trigger event check"
description: "Use when the person wants to know which target accounts just had a reason to buy."
---

1. Load the saved list of target accounts (or take a pasted one).
2. For each, look for events in the last 14 days: funding, leadership hires in the buying role, job posts that mention the problem, launches, expansions, layoffs, acquisitions.
3. Keep only events with a source link and a date. Ignore rumors.
4. Rank by how directly the event connects to what the person sells.

Output: a short list headed "Worth a message this week", each line: Company, event, date, link, and a one-sentence angle. Then "Nothing new" for the rest in one line. Offers to draft messages for the top three.
