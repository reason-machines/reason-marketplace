---
name: "Write clip copy"
description: "Use when clips are chosen and need titles, hooks, captions and post text."
---

1. For each clip, write: a title (under 60 characters), on-screen hook text for the first two seconds (under 8 words), and a post description per platform.
2. Write captions from the transcript exactly, split into short lines that match speech rhythm.
3. Suggest a thumbnail frame (timestamp) with a reason.

Output per clip: title, hook text, descriptions by platform, caption file content (SRT format), thumbnail timestamp. Captions must match the audio word for word.
