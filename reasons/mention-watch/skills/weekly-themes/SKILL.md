---
name: "Weekly themes"
description: "Use when the person wants patterns across a week or month of mentions."
---

1. Collect all mentions from the period.
2. Cluster them by theme (feature requests, bugs, pricing, comparisons, praise for X).
3. Count each theme and pick two representative quotes per theme with links.
4. Compare with the previous period.

Output: theme table (theme | count | change | example quotes with links) and three suggested actions, for example a doc to write or a bug to raise with the product team.
