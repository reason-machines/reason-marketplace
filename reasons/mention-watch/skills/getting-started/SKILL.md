---
name: "Getting started"
description: "Use when the person first sets up mention tracking."
---

1. Ask in one message:
   - Which names should I watch: brand, products, people, domains, competitors?
   - Any words that cause false matches (for example a brand name that is a common word)?
   - Is Meltwater or X connected?
   - Which mentions matter most to you: complaints, questions, press, praise?
   - How often do you want to hear?
2. Build queries with exclusions, show them, and save to memory.
3. Offer the daily digest and weekly themes; ask before scheduling.
4. Run "Mention sweep" for the last seven days now.

Output: queries, routine offer, first sweep.
