---
name: "Mention sweep"
description: "Use when the person wants recent mentions collected and sorted."
---

1. Run each saved query across connected sources (Meltwater, X, Exa) and web search, from the last run time.
2. Remove duplicates, reposts, spam and false matches.
3. Classify each mention and estimate reach.
4. Select those worth action, with the reason.

Output:
- Act on these: source | author | date | quote (exact, short) | type | why it matters | suggested next step | link
- Everything else: counts by type and source
- Queries that returned nothing or failed
