---
name: "Draft a post"
description: "Use when the person wants a blog post, guide or article written from a topic, brief or notes."
---

1. Restate the brief in four lines: reader, main point, call to action, target length. Ask only if one is missing and cannot be inferred.
2. Read every source the person gave. Then search the web for two to five supporting sources; prefer primary sources (official docs, studies, company data).
3. Write an outline: working headline, three headline alternatives, H2 sections with one sentence each on what the section proves.
4. Write the draft in the saved voice. Open with the reader's problem, not a definition. Use one concrete example per section.
5. Edit pass: cut filler intros, hedges and repeated points; check every claim against the source list.

Output:
- Headline plus three alternatives
- The draft in Markdown
- Sources: numbered links
- Unverified: claims needing a check
- SEO: meta title (under 60 characters), meta description (under 155), three internal link suggestions

Never publish or schedule; the draft waits for approval.
