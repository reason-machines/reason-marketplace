---
name: "Stage in the CMS"
description: "Use when an approved draft should be placed in Notion, WordPress.com or Webflow as an unpublished draft."
---

1. Confirm the draft is approved and which destination to use. If the plugin is not connected, show the connection card and offer a Markdown or HTML file instead.
2. Map fields: title, slug, excerpt, meta title, meta description, category, tags, author.
3. Create the entry as a draft only. Never set it to published or scheduled.
4. Read the draft back from the CMS and compare the title, headings and links with the approved version.

Output:
- Where it is (link to the draft)
- Fields set
- Anything that did not carry over (embeds, tables, images) and what the person must add by hand

If the CMS refuses the change, report the exact error and what the person can do next.
