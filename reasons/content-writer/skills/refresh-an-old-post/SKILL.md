---
name: "Refresh an old post"
description: "Use when the person wants an existing post updated, or asks which old posts need work."
---

1. Fetch the live post (or read the pasted text).
2. Check every factual claim, statistic, link, product name, price and screenshot description against current sources and the person's site.
3. List what is outdated, broken or missing, and what newer information deserves a section.
4. Rewrite only the parts that need it, keeping the URL, headline intent and the author's voice.

Output:
- Change log table: section | problem | fix | source
- The revised post in Markdown with changed passages marked [updated]
- Suggested new date line only if the person wants it

Never change the URL or delete sections without saying so. Never publish the update myself.
